# Registro de ensayos

`bench_log.csv` es una plantilla vacía. Copiar antes de usar. Unidades en nombres de columna; tiempos en segundos. Usar `true` / `false` para observaciones booleanas y dejar vacío lo que no se midió. La columna `total_seconds` debe referirse al mismo intervalo de trabajo en todas las muestras. No mezclar mediciones físicas y estimaciones de CAD en una misma fila.
